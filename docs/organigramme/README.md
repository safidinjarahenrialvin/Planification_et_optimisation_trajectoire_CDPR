# Organigrammes de la chaîne logicielle

Ce dossier contient les quatre organigrammes de la chaîne logicielle présentée dans la partie 3 du mémoire :

1. `bloc_1_preparation_donnees` — préparation des données et construction du modèle ;
2. `bloc_2_espace_travail` — génération et filtrage de l’espace de travail ;
3. `bloc_3_optimisation_trajectoires` — calcul des coûts et optimisation NSGA-II ;
4. `bloc_4_validation_profilage_comparaison` — profilage, validation et comparaison.

Les fichiers `.mmd` sont les sources Mermaid modifiables. Les fichiers `.png` sont les rendus prêts à être insérés dans le rapport.
