# Mémoire SP2 — Structure Overleaf

## Compilation
1. Compiler avec **pdfLaTeX** (2 à 3 passes).
2. Moteur recommandé : pdfLaTeX.

## Structure
- `main.tex` : fichier principal
- `config/` : packages, mise en page, commandes
- `frontmatter/` : page de garde, remerciements, etc.
- `chapters/` : introduction, cadrage, chapitres I–III
- `figures/` : images (aussi organisées par chapitre)
- `references.bib` : références BibTeX (optionnel)
